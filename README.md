## 🌟 จุดเด่นของผลงาน (Project Highlights)

* 🎨 **PBR Realistic Materials**: พื้นไม้ White Oak Veneer ธรรมชาติ ผสานผนังหิน Travertine Stone โทนอุ่นแบบ Seamless UV Mapping พร้อม Normal & Roughness maps
* ☕ **Custom GLSL Vertex Shaders**:
  * จำลองผิวน้ำกาแฟกระเพื่อมเป็นคลื่นตามเวลา (Vertex wave displacement) บนแก้วกาแฟหูจับตัว C ทรง 3 มิติ
  * ยอดใบไม้พลิ้วไหวตามแรงลมเสมือนจริง (Gentle Wind Sway)
* 🌓 **Dynamic Day / Night Theme**: ระบบสลับบรรยากาศกลางวัน-กลางคืน พร้อมปรับสภาพแสงไฟนีออนติดผนัง และโคมไฟตั้งโต๊ะแบบเรียลไทม์
* 🎯 **Smooth Object Picking & Camera Focus**: ใช้ Raycasting ตรวจจับการคลิกวัตถุ พร้อมแอนิเมชันเลื่อนมุมมองกล้องเข้าหาชิ้นงานอย่างนุ่มนวล
* ☁️ **Animated Sky & Clouds**: ก้อนเมฆ 3D ลอยผ่านหน้าต่างอย่างต่อเนื่อง สร้างมิติและความมีชีวิตชีวาให้ห้อง
* 🔒 **Smart Camera Orbit**: ล็อกองศากล้องไม่ให้หลุดออกไปเห็นกำแพงด้านหลัง รักษาความสวยงามในทุกมุมมอง

## 🎮 วิธีการควบคุม (Navigation & Controls)

* **คลิกซ้าย + ลาก**: หมุนมุมมองรอบห้อง (Orbit Rotate)
* **คลิกขวา + ลาก**: เลื่อนตำแหน่งกล้อง (Pan)
* **สกอร์เมาส์**: ซูมเข้า - ออก (Zoom In / Out)
* **คลิกที่วัตถุ**: ซูมเจาะลึกดูรายละเอียด เช่น หน้าจอคอม, แก้วกาแฟ, ป้ายนิสิต, โคมไฟ
* **ปุ่มเมนูด้านบน**: เปลี่ยนมุมมองลัด / สลับโหมด Day & Night
