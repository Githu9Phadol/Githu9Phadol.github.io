*ห้อง 3 มิติเชิงโต้ตอบสมบูรณ์แบบ พัฒนาด้วย Three.js, Blender และ Custom GLSL Shaders*

* ✨ **PBR Texture Mapping**: พื้นไม้ White Oak Veneer และผนังหิน Travertine Stone แบบ Seamless UV
* ☕ **Custom GLSL Shaders**: ผิวน้ำกาแฟกระเพื่อมเป็นคลื่นตามเวลา (Wave displacement) บนแก้วกาแฟ 3D หูจับทรงตัว C และยอดใบไม้พลิ้วไหวตามลม
* 🌓 **Real-time Day & Night Mode**: สลับบรรยากาศกลางวันและกลางคืน พร้อมปรับไฟนีออนและโคมไฟโต๊ะทำงานแบบสมจริง
* 🎯 **Smooth Object Raycasting**: คลิกซูมดูรายละเอียดวัตถุในห้อง เช่น หน้าจอคอม, แก้วกาแฟ, ป้ายชื่อนิสิต
